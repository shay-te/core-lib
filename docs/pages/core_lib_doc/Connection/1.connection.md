Every data source — Postgres, MongoDB, Solr, Neo4j — has a different client API and a different session lifecycle. Core-Lib does not hide those native APIs. It gives them the same outer shape, so your `DataAccess` classes receive a `Connection` and use `with conn.get() as client:` every time.

Core-Lib's `Connection` layer solves the lifecycle part with a single pattern: `with conn.get() as session:`. Every data source exposes a context manager that handles open/use/close behavior. Your query code still uses the native client; the lifecycle and wiring stay consistent.

> **Where it fits:** Connection layer. `CoreLib.__init__` creates connection factories and passes them into `DataAccess`; `Service` classes should not see them directly.

> Unfamiliar with terms like "context manager" or "session"? See the [Glossary](/glossary.html).

## The Connection base class

*core_lib.connection.connection.Connection* [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/connection/connection.py#L6){:target="_blank"}

`Connection` is the abstract base class. It implements `__enter__` to allocate and return a session or client, and `__exit__` to release resources — so every concrete connection works with Python's `with` statement.

## Built-in Connections

Core-Lib ships with six built-in connection types. Each provides the same `with conn.get() as x:` shape; `x` is the native client for that data source.

### Database (SQLAlchemy)

The default relational-database connection. Works with Postgres, MySQL, SQLite, and anything else SQLAlchemy supports.

- `SqlAlchemyConnectionFactory` [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/connection/sql_alchemy_connection_factory.py){:target="_blank"}
- `SqlAlchemyConnection` [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/connection/sql_alchemy_connection.py){:target="_blank"}

### MongoDB

Uses [PyMongo](https://pymongo.readthedocs.io/en/stable/){:target="_blank"} to provide the `MongoClient` instance.

- `MongoDBConnectionFactory` [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/connection/mongodb_connection_factory.py){:target="_blank"}
- `MongoDBConnection` [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/connection/mongodb_connection.py){:target="_blank"}

### Neo4j

Uses [neo4j-python-driver](https://github.com/neo4j/neo4j-python-driver){:target="_blank"} to provide the `neo4j.Session` instance.

- `Neo4jConnectionFactory` [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/connection/neo4j_connection_factory.py){:target="_blank"}
- `Neo4jConnection` [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/connection/neo4j_connection.py){:target="_blank"}

### Solr

Uses [pysolr](https://github.com/django-haystack/pysolr/){:target="_blank"} to provide the `pysolr.Solr` client.

- `SolrConnectionFactory` [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/connection/solr_connection_factory.py){:target="_blank"}
- `SolrConnection` [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/connection/solr_connection.py){:target="_blank"}

### Elasticsearch

Uses the [elasticsearch-py](https://www.elastic.co/guide/en/elasticsearch/client/python-api/current/index.html){:target="_blank"} client.

- `ElasticSearchConnectionFactory` [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/connection/elasticsearch_connection_factory.py){:target="_blank"}
- `ElasticSearchConnection` [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/connection/elasticsearch_connection.py){:target="_blank"}

### Generic object wrapper

`ObjectConnectionFactory` wraps any plain Python object in the `with conn.get() as obj:` pattern — useful for testing or non-DB data sources.

- `ObjectConnectionFactory` [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/connection/object_connection_factory.py){:target="_blank"}
- `ObjectConnection` [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/connection/object_connection.py){:target="_blank"}

*core_lib.connection.connection_factory_registry.ConnectionFactoryRegistry* [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/connection/connection_factory_registry.py#L13){:target="_blank"}
