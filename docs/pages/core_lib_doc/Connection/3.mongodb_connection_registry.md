`MongoDBConnectionFactory` creates one PyMongo `MongoClient` from config when it is built, and hands that same client to every `with mongodb.get() as client:` block. A `MongoClient` is a connection pool and should be reused, so build the factory once, in `CoreLib.__init__`. The `with` block does **not** close the client on exit.

**What it adds over PyMongo:** very little. It builds the client from config and gives your `DataAccess` the same `.get()` shape as every other Core-Lib connection, which makes it easy to [test without a server](#testing-without-a-server). Inside the block you use the normal PyMongo API. The factory passes only the URL to `MongoClient`; other `MongoClient` options have no config key. If you need them, build the client yourself and wrap it in an [`ObjectConnectionFactory`](object_connection_factory.html).

> **Where it fits:** Connection layer for MongoDB. Build it in `CoreLib.__init__`, pass it to your MongoDB `DataAccess` classes, and keep PyMongo calls out of `Service` classes.

## Example

### `your_core_lib.yaml`

```yaml
# @package _global_
core_lib:
  data:
    mongodb:
      _target_: core_lib.connection.mongodb_connection_factory.MongoDBConnectionFactory
      config:
        url:
          protocol: mongodb
          host: ${oc.env:MONGO_HOST}
          port: 27017
          username: ${oc.env:MONGO_USERNAME}
          password: ${oc.env:MONGO_PASSWORD}
```

This builds `mongodb://<user>:<password>@<host>:27017`. For a `mongodb+srv` URL (MongoDB Atlas), leave out `port`: PyMongo rejects a port in an SRV URL. Percent-encode a password that contains `@`, `:` or `/` (see [Connection](connection.html#how-a-connection-is-configured)).

### `your_core_lib.py`

```python
from omegaconf import DictConfig

from core_lib.core_lib import CoreLib
from core_lib.helpers.config_instances import instantiate_config

from your_core_lib.data_layers.data_access.user_data_access import UserDataAccess
from your_core_lib.data_layers.service.user_service import UserService


class YourCoreLib(CoreLib):
    def __init__(self, config: DictConfig):
        super().__init__()
        self.config = config
        mongodb = instantiate_config(self.config.core_lib.data.mongodb)
        self.user = UserService(UserDataAccess(mongodb))
```

Each `instantiate_config` call creates a new factory with its own `MongoClient`. To share one client between several Core-Libs in the same process, add an `_instance_key_` to the block and build it with `CoreLib.connection_factory_registry.get_or_reg(...)` instead (see [Connection](connection.html#sharing-a-connection-between-core-libs)).

### `user_data_access.py`

`app` is the database and `users` the collection. The methods return plain values, so services never see PyMongo result types.

```python
from core_lib.connection.mongodb_connection_factory import MongoDBConnectionFactory
from core_lib.data_layers.data_access.data_access import DataAccess


class UserDataAccess(DataAccess):

    def __init__(self, mongodb: MongoDBConnectionFactory):
        self._mongodb = mongodb

    def get(self, user_id: int) -> dict:
        with self._mongodb.get() as client:
            return client['app']['users'].find_one({'_id': user_id})

    def create(self, user_id: int, data: dict) -> int:
        with self._mongodb.get() as client:
            return client['app']['users'].insert_one({'_id': user_id, **data}).inserted_id

    def update(self, user_id: int, data: dict) -> int:
        with self._mongodb.get() as client:
            return client['app']['users'].update_one({'_id': user_id}, {'$set': data}).modified_count

    def delete(self, user_id: int) -> int:
        with self._mongodb.get() as client:
            return client['app']['users'].delete_one({'_id': user_id}).deleted_count
```

### Testing without a server

`UserDataAccess` only calls `.get()` on what it is given, so a test can hand it an in-memory MongoDB from [mongomock](https://github.com/mongomock/mongomock){:target="_blank"} (installed with Core-Lib), wrapped in an `ObjectConnectionFactory`:

```python
import mongomock

from core_lib.connection.object_connection_factory import ObjectConnectionFactory

from your_core_lib.data_layers.data_access.user_data_access import UserDataAccess

user_data_access = UserDataAccess(ObjectConnectionFactory(mongomock.MongoClient()))
user_data_access.create(1, {'name': 'Jane'})
print(user_data_access.get(1))  # {'_id': 1, 'name': 'Jane'}
```

## MongoDBConnection

*core_lib.connection.mongodb_connection.MongoDBConnection* [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/connection/mongodb_connection.py){:target="_blank"}

Returns the factory's `MongoClient` from `__enter__`. `__exit__` does nothing.

```python
class MongoDBConnection(Connection):
    def __init__(self, mongo_client: MongoClient):
        self.mongo_client = mongo_client
```
**Arguments**

- **`mongo_client`** *`(MongoClient)`*: The client created by `MongoDBConnectionFactory`.
