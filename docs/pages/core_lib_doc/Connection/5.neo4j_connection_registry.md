`Neo4jConnectionFactory` creates one [Neo4j driver](https://github.com/neo4j/neo4j-python-driver){:target="_blank"} from config when it is built. Every `with neo4j_factory.get() as session:` block gets a new `neo4j.Session` from that driver, and the session is closed when the block exits.

**What it adds over the Neo4j driver:** little. The driver already supports `with driver.session() as session:`. The factory builds the driver from config and gives your `DataAccess` the same `.get()` shape as every other Core-Lib connection, so a test can pass in an [`ObjectConnectionFactory`](object_connection_factory.html) instead. It also always turns encryption off (see the note under the YAML).

> **Where it fits:** Connection layer for graph data. Build it in `CoreLib.__init__`, pass it to your graph `DataAccess` classes, and keep Cypher queries out of `Service` classes.

## Example

### `your_core_lib.yaml`

```yaml
# @package _global_
core_lib:
  data:
    neo4j:
      _target_: core_lib.connection.neo4j_connection_factory.Neo4jConnectionFactory
      config:
        credentials:
          username: ${oc.env:NEO4J_USERNAME}
          password: ${oc.env:NEO4J_PASSWORD}
        url:
          protocol: bolt   # or neo4j
          host: ${oc.env:NEO4J_HOST}
          port: 7687       # the Bolt port (7474 is the HTTP port)
```

This builds `bolt://<host>:7687`. Always set `protocol`. Without it the URL has no scheme: most hosts then fail at startup with a `ConfigurationError`, and a host named `neo4j` (a common docker-compose service name) is read as the scheme, so the driver silently connects to `localhost:7687` instead.

The factory passes `encrypted=False` to the driver, so only the plain schemes `bolt` and `neo4j` work. Encrypted schemes such as `neo4j+s` and `bolt+s`, which Neo4j Aura requires, are rejected by the driver with a `ConfigurationError`. For those, create the driver yourself and wrap it in an `ObjectConnectionFactory` with `new_session_callback=lambda driver: driver.session()` and `close_session_callback=lambda session: session.close()`.

### `your_core_lib.py`

```python
from omegaconf import DictConfig

from core_lib.core_lib import CoreLib
from core_lib.helpers.config_instances import instantiate_config

from your_core_lib.data_layers.data_access.user_graph_data_access import UserGraphDataAccess
from your_core_lib.data_layers.service.user_graph_service import UserGraphService


class YourCoreLib(CoreLib):
    def __init__(self, config: DictConfig):
        super().__init__()
        self.config = config
        neo4j_factory = instantiate_config(self.config.core_lib.data.neo4j)
        self.user_graph = UserGraphService(UserGraphDataAccess(neo4j_factory))
```

### `user_graph_data_access.py`

Read what you need from a result **inside** the block, with `.data()` or `.single()`. The session closes when the block exits, and a result read after that raises `ResultConsumedError`. Reading inside the block also means services get plain dicts, not Neo4j types.

{% raw %}
```python
from core_lib.connection.neo4j_connection_factory import Neo4jConnectionFactory
from core_lib.data_layers.data_access.data_access import DataAccess


class UserGraphDataAccess(DataAccess):

    def __init__(self, neo4j_factory: Neo4jConnectionFactory):
        self._neo4j_factory = neo4j_factory

    def search_by_name(self, prefix: str) -> list:
        with self._neo4j_factory.get() as session:
            result = session.run(
                'MATCH (u:User) WHERE u.name STARTS WITH $prefix '
                'RETURN u.user_id AS user_id, u.name AS name',
                prefix=prefix,
            )
            return result.data()

    def create(self, user_id: int, name: str):
        with self._neo4j_factory.get() as session:
            session.run(
                'MERGE (u:User {user_id: $user_id}) ON CREATE SET u.name = $name',
                user_id=user_id, name=name,
            ).consume()

    def rename(self, user_id: int, name: str) -> dict:
        with self._neo4j_factory.get() as session:
            record = session.run(
                'MATCH (u:User {user_id: $user_id}) SET u.name = $name RETURN u',
                user_id=user_id, name=name,
            ).single()
            return dict(record['u']) if record else None
```
{% endraw %}

- `search_by_name('Ja')` returns a list of dicts such as `[{'user_id': 1, 'name': 'Jane'}]`.
- `create` writes a `User` node unless one with that `user_id` already exists. `.consume()` waits for the write to finish, so a failed write raises inside the block. Without it, the write finishes when the session closes, and the driver only logs a failure there as a warning.
- `rename` returns the node's properties as a dict, or `None` when no user has that `user_id`.

Pass values as query parameters (`$name`); never paste them into the Cypher string.

## Functions

### \_\_init\_\_()

*core_lib.connection.neo4j_connection_factory.Neo4jConnectionFactory.\_\_init\_\_()* [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/connection/neo4j_connection_factory.py){:target="_blank"}

Creates the driver with `GraphDatabase.driver(build_url(**config.url), auth=basic_auth(username, password), encrypted=False)`. Nothing is sent to Neo4j until the first query.

```python
def __init__(self, config: DictConfig):
```

**Arguments**

- **`config`** *`(DictConfig)`*: A node with a `url` block and a `credentials` block holding `username` and `password` (the `config:` node of the YAML block above).

### driver

*core_lib.connection.neo4j_connection_factory.Neo4jConnectionFactory.driver* [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/connection/neo4j_connection_factory.py){:target="_blank"}

The factory's driver. This is a property: write `neo4j_factory.driver`, not `neo4j_factory.driver()`.

```python
@property
def driver(self) -> GraphDatabase:
```

**Returns**

*`(neo4j.Driver)`*: The driver created in `__init__`: a `BoltDriver` for a `bolt://` URL, a `Neo4jDriver` for a `neo4j://` URL. (The type hint in the source says `GraphDatabase`, which is the class that creates drivers, not what is returned.)

### get()

*core_lib.connection.neo4j_connection_factory.Neo4jConnectionFactory.get()* [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/connection/neo4j_connection_factory.py){:target="_blank"}

Opens a new `neo4j.Session` on the driver and returns it in a `Neo4jConnection`. Use it in a `with` statement so the session is closed.

```python
def get(self, *args, **kwargs) -> Neo4jConnection:
```

**Arguments**

- __`*args, **kwargs`__: Ignored.

**Returns**

*`(Neo4jConnection)`*: A `Neo4jConnection` holding the new session.

## Neo4jConnection

*core_lib.connection.neo4j_connection.Neo4jConnection* [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/connection/neo4j_connection.py){:target="_blank"}

Returns its `neo4j.Session` from `__enter__`, and closes it in `__exit__`.

```python
class Neo4jConnection(Connection):
    def __init__(self, neo4j_session: Session):
        self.neo4j_session = neo4j_session
```
**Arguments**

- **`neo4j_session`** *`(Session)`*: The `neo4j.Session` opened by `Neo4jConnectionFactory.get()`.
