`ElasticSearchConnectionFactory` creates one `Elasticsearch` client from config when it is built, and hands that same client to every `with elasticsearch.get() as client:` block. The client manages its own connection pool, so build the factory once, in `CoreLib.__init__`. The `with` block does **not** close the client on exit.

**What it adds over elasticsearch-py:** very little. It builds the client from config and gives your `DataAccess` the same `.get()` shape as every other Core-Lib connection, so a test can pass in an [`ObjectConnectionFactory`](object_connection_factory.html) instead. Inside the block you use the normal [elasticsearch-py](https://www.elastic.co/guide/en/elasticsearch/client/python-api/current/index.html){:target="_blank"} API. The factory passes only the URL to `Elasticsearch(...)`; API keys, CA certificates and timeouts have no config key. If you need them, build the client yourself and wrap it in an `ObjectConnectionFactory`.

**Install the client yourself.** `pip install core-lib` does not install `elasticsearch`, and importing `core_lib.connection.elasticsearch_connection_factory` without it fails with `ModuleNotFoundError`. Install the client whose major version matches your cluster, for example `pip install "elasticsearch>=8,<9"` for Elasticsearch 8.

> **Where it fits:** Connection layer for Elasticsearch. Build it in `CoreLib.__init__`, pass it to your search `DataAccess` classes, and keep index names and query bodies out of `Service` classes.

*core_lib.connection.elasticsearch_connection_factory.ElasticSearchConnectionFactory* [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/connection/elasticsearch_connection_factory.py){:target="_blank"}

## Example

### `your_core_lib.yaml`

```yaml
# @package _global_
core_lib:
  data:
    elasticsearch:
      _target_: core_lib.connection.elasticsearch_connection_factory.ElasticSearchConnectionFactory
      config:
        url:
          protocol: https
          host: ${oc.env:ES_HOST}
          port: ${oc.env:ES_PORT}
          username: ${oc.env:ES_USER}
          password: ${oc.env:ES_PASSWORD}
```

This builds `https://<user>:<password>@<host>:<port>`. The client sends the username and password as HTTP basic auth.

### `your_core_lib.py`

```python
from omegaconf import DictConfig

from core_lib.core_lib import CoreLib
from core_lib.helpers.config_instances import instantiate_config

from your_core_lib.data_layers.data_access.product_search_data_access import ProductSearchDataAccess
from your_core_lib.data_layers.service.product_search_service import ProductSearchService


class YourCoreLib(CoreLib):
    def __init__(self, config: DictConfig):
        super().__init__()
        self.config = config
        elasticsearch = instantiate_config(self.config.core_lib.data.elasticsearch)
        self.product_search = ProductSearchService(ProductSearchDataAccess(elasticsearch))
```

Each `instantiate_config` call creates a new factory with its own client. To share one client between several Core-Libs in the same process, add an `_instance_key_` to the block and build it with `CoreLib.connection_factory_registry.get_or_reg(...)` instead (see [Connection](connection.html#sharing-a-connection-between-core-libs)).

### `product_search_data_access.py`

The `DataAccess` owns the index name and the query body. The service asks for products by name and gets plain dicts back.

{% raw %}
```python
from core_lib.connection.elasticsearch_connection_factory import ElasticSearchConnectionFactory
from core_lib.data_layers.data_access.data_access import DataAccess


class ProductSearchDataAccess(DataAccess):

    INDEX = 'products'

    def __init__(self, elasticsearch: ElasticSearchConnectionFactory):
        self._elasticsearch = elasticsearch

    def search_by_name(self, text: str, limit: int = 20) -> list:
        with self._elasticsearch.get() as client:
            response = client.search(index=self.INDEX, query={'match': {'name': text}}, size=limit)
            return [hit['_source'] for hit in response['hits']['hits']]

    def index_product(self, product_id: str, product: dict):
        with self._elasticsearch.get() as client:
            client.index(index=self.INDEX, id=product_id, document=product)

    def delete_product(self, product_id: str):
        with self._elasticsearch.get() as client:
            client.delete(index=self.INDEX, id=product_id)
```

## API reference

### `__init__()`

Creates the client with `Elasticsearch(build_url(**config.url))`. Nothing is sent to Elasticsearch until the first request.

```python
def __init__(self, config: DictConfig):
```

**Arguments**

- **`config`** *`(DictConfig)`*: A node with a `url` block (the `config:` node of the YAML block above).

### `client`

The factory's `Elasticsearch` client, without going through `get()`. This is a property.

```python
@property
def client(self) -> Elasticsearch:
```

**Returns**

*`(Elasticsearch)`*: The `elasticsearch.Elasticsearch` client created in `__init__`.

### `get()`

Returns a new `ElasticSearchConnection` that holds the factory's client.

```python
def get(self, *args, **kwargs) -> ElasticSearchConnection:
```

**Returns**

*`(ElasticSearchConnection)`*: Returns the client from `__enter__`. `__exit__` does nothing; the client stays open for the next block.
