`ObjectConnectionFactory` wraps any Python object in Core-Lib's `with factory.get() as obj:` pattern. Use it when a `DataAccess` needs something that none of the built-in factories covers: an in-memory store, a client you build yourself, or a fake in a test.

**What it adds:** only the `.get()` shape, and optional open and close callbacks. That is the point: a `DataAccess` written against `.get()` works the same with a real connection factory or with this one, so a test can hand it a fake (see the [MongoDB example](mongodb_connection_factory.html#testing-without-a-server)).

> **Where it fits:** Connection layer for nonstandard data sources. Build it in `CoreLib.__init__` (or in a test) and pass it to a `DataAccess`.

*core_lib.connection.object_connection_factory.ObjectConnectionFactory* [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/connection/object_connection_factory.py){:target="_blank"}

## Usage

{% raw %}
```python
from core_lib.connection.object_connection_factory import ObjectConnectionFactory


# Wrap any object
my_store = {'users': {}}
factory = ObjectConnectionFactory(my_store)

with factory.get() as store:
    store['users'][1] = {'name': 'Alice'}

print(my_store)  # {'users': {1: {'name': 'Alice'}}}
```
{% endraw %}

With callbacks, each `get()` can open something new, and the end of the `with` block closes it. Here every block gets its own SQLite connection:

```python
import sqlite3

from core_lib.connection.object_connection_factory import ObjectConnectionFactory


def open_session(path):
    return sqlite3.connect(path)    # called by every factory.get()


def close_session(connection):
    connection.close()              # called when the with block exits


factory = ObjectConnectionFactory('app.db', new_session_callback=open_session, close_session_callback=close_session)

with factory.get() as connection:
    print(connection.execute('SELECT 1').fetchone())  # (1,)
```

The close callback runs whether or not the block raised, and it is not told about the exception. So do not commit in it; commit inside the block.

## API reference

### `__init__()`

```python
def __init__(self, obj, new_session_callback=None, close_session_callback=None):
```

**Arguments**

- **`obj`**: The object to wrap.
- **`new_session_callback`**: Default `None`. Called with `obj` by every `get()` call. Its return value is what the `with` block receives. Use it to open, connect or copy something per block. Because it runs in `get()`, always use `get()` in a `with` statement, or the close callback never runs.
- **`close_session_callback`**: Default `None`. Called with what the `with` block received, when the block exits.

### `object`

The wrapped object itself, without calling any callback. This is a property.

```python
@property
def object(self):
```

### `get()`

Calls `new_session_callback` if there is one, and returns an `ObjectConnection`.

```python
def get(self, *args, **kwargs) -> ObjectConnection:
```

**Returns**

*`(ObjectConnection)`*: Returns the object (or the result of `new_session_callback`) from `__enter__`, and calls `close_session_callback` on `__exit__` if one was given.

## ObjectConnection

*core_lib.connection.object_connection.ObjectConnection* [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/connection/object_connection.py){:target="_blank"}

```python
class ObjectConnection(Connection):
    def __init__(self, obj, close_callback):
```

**Arguments**

- **`obj`**: The object to return from `__enter__`.
- **`close_callback`**: Called with `obj` on `__exit__`, if it is not `None`.
