When you delete a database row, it's gone. Soft delete keeps the row but marks it as deleted — so you retain audit history, can recover records, and don't break foreign key references. `SoftDeleteMixin` and `SoftDeleteTokenMixin` add the columns used by Core-Lib's soft-delete data access classes.

> **Where it fits:** Data entity support. Add these mixins to SQLAlchemy entities, then use a soft-delete `DataAccess` base class to update the columns.

## SoftDeleteMixin

*core_lib.data_layers.data.db.sqlalchemy.mixins.soft_delete_mixin.SoftDeleteMixin* [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/data_layers/data/db/sqlalchemy/mixins/soft_delete_mixin.py#L6){:target="_blank"}

`SoftDeleteMixin` creates the following columns in a table.
- `created_at`:
  - type: `DateTime`
  - default: `datetime.utcnow`


- `updated_at`:
  - type: `DateTime`
  - default: `datetime.utcnow`
  - onupdate: `datetime.utcnow` — automatically set to the current time whenever the row is updated (including when `deleted_at` is set during a soft delete).


- `deleted_at`:
  - type: `DateTime`
  - default: `None`
  - Set to `datetime.utcnow()` when the row is soft deleted.

```python
class SoftDeleteMixin(object):
    created_at = Column(DateTime, default=datetime.utcnow)
    created_at._creation_order = 9998
    updated_at = Column(DateTime, default=datetime.utcnow, onupdate=datetime.utcnow)
    updated_at._creation_order = 9998
    deleted_at = Column(DateTime, default=None)
    deleted_at._creation_order = 9998
```



## SoftDeleteTokenMixin

*core_lib.data_layers.data.db.sqlalchemy.mixins.soft_delete_token_mixin.SoftDeleteTokenMixin* [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/data_layers/data/db/sqlalchemy/mixins/soft_delete_token_mixin.py#L4){:target="_blank"}

`SoftDeleteTokenMixin` adds an integer column you can index for fast queries on deleted rows. Use it when your app frequently filters or sorts by deleted records.

> Skip this mixin if you don't need to query deleted rows by `deleted_at` often.

- `deleted_at_token`:
  - type: `Integer`
  - default: `0`
  - When you update `deleted_at`, also set `deleted_at_token` to `int(datetime.utcnow().timestamp())` so the indexed column stays in sync.

```python
class SoftDeleteTokenMixin(object):
    deleted_at_token = Column(Integer, default=0)
    deleted_at_token._creation_order = 9998
```



## Example

```python
from datetime import datetime
from sqlalchemy import Integer, Column, VARCHAR
from core_lib.data_layers.data.db.sqlalchemy.base import Base
from core_lib.data_layers.data.db.sqlalchemy.mixins.soft_delete_mixin import SoftDeleteMixin
from core_lib.data_layers.data.db.sqlalchemy.mixins.soft_delete_token_mixin import SoftDeleteTokenMixin


class UserData(Base, SoftDeleteMixin, SoftDeleteTokenMixin):
    __tablename__ = 'user_data'
    id = Column(Integer, primary_key=True, nullable=False)
    name = Column(VARCHAR(255), nullable=False, default="")


def soft_delete_user(session, user_id):
    now = datetime.utcnow()
    session.query(UserData).filter(UserData.id == user_id).update({
        'deleted_at': now,
        'deleted_at_token': int(now.timestamp()),
    })
```
