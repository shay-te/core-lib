`CoreLibListener` is an abstract class that tells you when your `CoreLib` instance starts (`start_core_lib()`) and when it is destroyed. Use it to start background work, warm caches, or release resources.

> **Where it fits:** Lifecycle hook on `CoreLib` itself. Attach listeners to your `CoreLib` instance, in its `__init__` or right after creating it, then call `start_core_lib()`.

*core_lib.core_lib_listener.CoreLibListener* [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/core_lib_listener.py){:target="_blank"}

## Usage

```python
from omegaconf import DictConfig, OmegaConf

from core_lib.core_lib import CoreLib
from core_lib.core_lib_listener import CoreLibListener


class YourCoreLib(CoreLib):
    def __init__(self, config: DictConfig):
        super().__init__()
        self.config = config


class AppListener(CoreLibListener):

    def on_core_lib_ready(self):
        # called by start_core_lib(): start jobs, warm caches, ...
        print('CoreLib is ready')

    def on_core_lib_destroy(self):
        # called when the CoreLib object is destroyed: release resources, flush buffers, ...
        print('CoreLib is shutting down')


config = OmegaConf.create({})  # your real config, usually loaded with Hydra
your_core_lib = YourCoreLib(config)
your_core_lib.attach_listener(AppListener())
your_core_lib.start_core_lib()  # prints: CoreLib is ready
del your_core_lib               # prints: CoreLib is shutting down
```

Jobs loaded with `load_jobs()` that are also `CoreLibListener`s are attached for you; see [Jobs](job.html).

## `CoreLib` methods

The examples below use `YourCoreLib`, `AppListener` and `config` from [Usage](#usage).

### start_core_lib()

*core_lib.core_lib.CoreLib.start_core_lib()* [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/core_lib.py){:target="_blank"}

Calls `on_core_lib_ready()` on every attached listener, then marks the instance as started. Call it once, after creating your `CoreLib` and attaching listeners.

Calling it a second time on the same instance raises `CoreLibInitException('CoreLib already initialized')`. If a listener's `on_core_lib_ready()` raises, `start_core_lib()` raises that exception and the instance is not marked as started.

```python
def start_core_lib(self):
```

**Example**

```python
your_core_lib = YourCoreLib(config)
your_core_lib.attach_listener(AppListener())
your_core_lib.start_core_lib()
```

### attach_listener()

*core_lib.core_lib.CoreLib.attach_listener()* [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/core_lib.py){:target="_blank"}

Attaches a listener to receive lifecycle events. It must be a `CoreLibListener`; anything else raises `AssertionError`.

```python
def attach_listener(self, core_lib_listener: CoreLibListener):
```

**Arguments**

- **`core_lib_listener`** *`(CoreLibListener)`*: An instance of a class that implements the abstract methods of `CoreLibListener`.

**Example**

```python
your_core_lib = YourCoreLib(config)
your_core_lib.attach_listener(AppListener())
```

### detach_listener()

*core_lib.core_lib.CoreLib.detach_listener()* [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/core_lib.py){:target="_blank"}

Removes a previously attached listener.

```python
def detach_listener(self, core_lib_listener: CoreLibListener):
```

**Arguments**

- **`core_lib_listener`** *`(CoreLibListener)`*: The listener instance to remove.

**Example**

```python
your_core_lib = YourCoreLib(config)
listener = AppListener()
your_core_lib.attach_listener(listener)
your_core_lib.detach_listener(listener)
```

### fire_core_lib_ready()

*core_lib.core_lib.CoreLib.fire_core_lib_ready()* [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/core_lib.py){:target="_blank"}

Notifies all listeners with `CoreLibListener.CoreLibEventType.CORE_LIB_READY`, which calls their `on_core_lib_ready()`. `start_core_lib()` calls it for you.

```python
def fire_core_lib_ready(self):
```

### fire_core_lib_destroy()

*core_lib.core_lib.CoreLib.fire_core_lib_destroy()* [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/core_lib.py){:target="_blank"}

Notifies all listeners with `CoreLibListener.CoreLibEventType.CORE_LIB_DESTROY`, which calls their `on_core_lib_destroy()`. `__del__` calls it for you.

```python
def fire_core_lib_destroy(self):
```

### \_\_del\_\_()

*core_lib.core_lib.CoreLib.\_\_del\_\_()* [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/core_lib.py){:target="_blank"}

The destructor. Calls `fire_core_lib_destroy()` when Python destroys the `CoreLib` object, which in CPython happens as soon as the last reference to it is gone. Python does not guarantee that `__del__` runs for objects still alive when the interpreter exits, so do not rely on `on_core_lib_destroy()` for cleanup that must always happen.

```python
def __del__(self):
```

**Example**

```python
your_core_lib = YourCoreLib(config)
your_core_lib.attach_listener(AppListener())
del your_core_lib  # last reference gone: on_core_lib_destroy() runs
```

## `CoreLibListener` methods

### on_core_lib_ready()

*core_lib.core_lib_listener.CoreLibListener.on_core_lib_ready()* [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/core_lib_listener.py){:target="_blank"}

Called by `start_core_lib()`. Implement it to run startup logic.

```python
@abstractmethod
def on_core_lib_ready(self):
```

### on_core_lib_destroy()

*core_lib.core_lib_listener.CoreLibListener.on_core_lib_destroy()* [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/core_lib_listener.py){:target="_blank"}

Called when the `CoreLib` object is destroyed. Implement it to run cleanup logic.

```python
@abstractmethod
def on_core_lib_destroy(self):
```

### update()

*core_lib.core_lib_listener.CoreLibListener.update()* [[source]](https://github.com/shay-te/core-lib/blob/master/core_lib/core_lib_listener.py){:target="_blank"}

Already implemented. `CoreLibListener` is an [`ObserverListener`](observer.html#observerlistener); this method routes the `CORE_LIB_READY` and `CORE_LIB_DESTROY` events to `on_core_lib_ready()` and `on_core_lib_destroy()`. You do not need to override it.

```python
def update(self, key: str, value):
```

**Arguments**

- **`key`** *`(CoreLibListener.CoreLibEventType)`*: The lifecycle event.
- **`value`**: Unused; always `None` for lifecycle events.
